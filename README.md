# Solarpunk Mod

A **Cities: Skylines II** mod for building car-free, climate-resilient cities.

- **Freight by rail**: garbage trains, cargo trams and freight metros instead of truck fleets
- **Last mile by cargo bike**, pedestrian green streets
- Later: **urban climate** — heat islands, stormwater, rewilding

One mod, organised in modules, building on great existing mods as dependencies.

**Status**: early research — nothing playable yet. Design notes (French): [`docs/design.md`](docs/design.md).
